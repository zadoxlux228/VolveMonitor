\# VolveMonitor



Клиент-серверное приложение для учёта нефтедобычи на месторождении Volve.



\## Архитектура



\- \*\*VolveApi\*\* — серверная часть на ASP.NET Core Web API + PostgreSQL + Entity Framework Core

\- \*\*VolveClient\*\* — клиентская часть на Angular + Angular Material



\## Функциональность



\### Авторизация

\- JWT-токены с разграничением ролей Admin / User

\- Защита эндпоинтов через guards на клиенте и атрибуты на сервере



\### Сущности

\- Месторождения (Fields)

\- Скважины (Wells) со статусами жизненного цикла

\- Замеры добычи (ProductionRecords)



\### Бизнес-логика

\- Запрет изменения статуса ликвидированной скважины

\- Валидация диапазонов датчиков (давление 0–500 bar, температура −20…200 °C)

\- Правила для нагнетательных скважин (WI): нефть = 0, вода > 0

\- Защита от дубликатов замеров и дат из будущего

\- Вычисляемые поля: обводнённость, эффективность, флаг аномалии



\### Аналитика

\- Сводный отчёт по месторождениям (GROUP BY, SUM, AVERAGE)

\- Топ скважин по добыче

\- Поиск аномальных замеров



\### Клиентская часть

\- Таблицы с сортировкой и карточки с переключением вида

\- Поиск и фильтры

\- Формы создания и редактирования с валидацией

\- Подтверждение удаления
